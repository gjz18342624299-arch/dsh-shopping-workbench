# 双11省钱情报局

DSH Desktop 购物工作台，提供购物需求分析、公开促销信息采集、购买安排与 .ics 日历导出。

## 功能与限制

- 使用 DSH 当前默认模型分析购物需求，给出平台、日期、优惠参考和领券步骤；模型输出可能有误，购买前须核对平台页面与结算条件。不保证最低价、优惠资格或推测日期。
- 可将建议加入购买安排，按日期与平台分组，导出包含提前 15 分钟提醒的 .ics 文件。提醒是否触发取决于导入后的日历应用。
- 后台具备北京时间每日 09:00 采集与手动重试入口；需要电脑、DSH、网络与默认模型可用。全平台完整性和无人值守连续运行尚未验收。
- 首次安装日历为空，只保留公开来源入口，不附带作者购物清单、采集正文、缓存或历史记录。采集失败不代表平台没有活动。

## 数据、网络与费用

数据根目录由宿主通过 dshHomePath('shopping-workbench') 注入。清单、日历和缓存位于该根目录的 outputs/，历史与诊断位于 work/、logs/；卸载不删除这些数据。

购物需求和相关证据会发送到用户在 DSH 配置的模型服务；搜索词会发送给 DSH 搜索服务或公开搜索入口，会产生已有模型/搜索服务的调用费用。公开网页用于提取促销资料。动态页面需要本机 Edge 或 Chrome；没有可用浏览器时无法渲染动态页面。不会自动领券、下单或付款。

## 开发

包校验：npm run check。包中不含安装生命周期脚本。使用标准包管理器安装依赖及打包前，应核对当前工具帮助。客户端文件 lib/client.js 已构建，不需要额外编译。

服务端本机接口前缀：/api/shopping-workbench/。数据目录通过 cordis.patch.yml 配置。
