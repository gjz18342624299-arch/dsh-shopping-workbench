# 双11省钱情报局

写下想买的东西，告诉你去哪个平台、哪天几点买、先领什么券。在 DSH Desktop 里当作一个工作台使用，数据都在你自己电脑上。

## 三步上手

1. **写下想买的。** 在页面上方的框里写，比如“戴森吹风机，预算 2000；凯乐石羽绒服”。一次写几件也行，品牌和预算可写可不写。
2. **点“给我排一下怎么买”。** 每件通常要 5 到 15 分钟，可以先去做别的，别关这个页面。完成后每件商品会显示推荐平台、购买时间和领券步骤。
3. **点“就按这个买”。** 商品会进入右边的“我的购物安排”，同一天同平台的会合在一起方便凑单。点“导出到手机日历”，导入后会在购买前 15 分钟提醒你。

拿不准的时候点“问 AI 怎么买”，右侧会打开 AI 助手，自动把这件商品的结论和活动信息发给它。AI 回答完后点“用 AI 的结论更新清单”，它说的平台和时间会直接写进清单，不用你抄。

## 第一次用需要什么

- DSH 里已经设置好一个默认模型。没设置的话页面顶部会有红色提示。
- 电脑能上网。分析和找活动都要联网。
- 促销日历装好就有内容（截至打包日期收集的各平台活动和券）。之后每天 9 点自动更新，时间可以在“采集设置”里改；想马上更新就打开“促销与领券日历”点“立即更新”，最长 45 分钟，可以先关掉窗口。

## 它不会做什么

- 不会自动领券、预约或下单，所有购买动作都由你自己完成。
- 给出的平台、日期和优惠是 AI 根据公开信息推断的，下单前请核对商品页面和结算价。
- 不保证最低价，也不保证你的账号一定能领到某张券。

## 数据与费用

清单、安排和日历保存在本机 DSH 数据目录的 shopping-workbench 文件夹里，卸载插件不会删除。分析购物需求和整理活动会调用你在 DSH 里设置的模型，可能产生该模型的调用费用。

## 开发者

包校验 `npm run check`。客户端文件 lib/client.js 已构建，不需要额外编译。服务端接口前缀 `/api/shopping-workbench/`。许可证 MIT。
